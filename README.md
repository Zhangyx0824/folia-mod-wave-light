# 动感波光 / wave-light

一个 [Folia](https://github.com/chthollyphile/folia-major)（Folium 1 模组系统）模组：新增一个**歌词动画模式**「动感波光」——选中它时，播放页面变成一片随封面主色呼吸的暗色水面：数条发光波带缓缓流动、明灭，光斑缓慢漂移；歌词居中排布，当前句染上与封面同源的亮色，其余句子低透明度淡出。效果参考 QQ 音乐的「动感波光」播放页。

**不选中这个模式时完全不渲染**，与内置及其他模组的歌词样式互不影响。

![preview](wave-light/preview.jpg)

## 使用

在播放界面的**动画模式选择器**里选「动感波光」即可。切回其他模式，波光立即消失。

## 功能

- **封面取色**：自动提取当前歌曲封面的主色（24×24 降采样加权提取，本机完成，不联网），背景暗色水波、光带颜色、歌词颜色全部由它派生；切歌自动换色。无封面 / 封面不可读时回退主题强调色。
- **波光动画**：canvas + 加法混合绘制的多条发光波带与漂移光斑，中间亮、四周暗；暂停时水面依然流动（参考原效果）。
- **歌词**：曲名 / 歌手、当前句（封面同源亮色）、翻译、下一句（可关），居中排布，换行动画淡入；字号跟随主题与用户歌词字号设置。
- **主题联动**：字体栈、字重取自当前主题。

## 设置

选中该模式后，在动画模式的设置面板里调整：

| 设置 | 说明 |
| --- | --- |
| 波光配色 | 跟随封面主色（默认）/ 主题色 |
| 波光亮度 | 光带与光斑的整体强度（默认 1，可 0.3–2） |
| 流动速度 | 波光流动的快慢（默认 1，可 0.2–3） |
| 光带数量 | 水面上光带的条数（默认 8，可 4–14） |
| 歌词字号 | 叠加在主题字号与用户歌词字号之上 |
| 显示下一句 | 下一句歌词的预览 |

## 安装

把 `wave-light/` 文件夹放进 Folia 的模组目录后重启：

```
~/Library/Application Support/Folia/mods/wave-light
```

首次启用时 Folia 会弹出确认窗口（列出内容指纹），确认后即可使用。

## 实现说明

- 通过公开注册表 `folium.registries.visualizers` 注册一个动画模式，`hostLayers: { background: false, subtitles: false }`——整个页面（背景 + 歌词）由模组自绘，宿主不再铺自己的背景层。
- 背景 = 封面主色派生的径向暗色渐变（DOM）；波光 = 单个 canvas，requestAnimationFrame 每帧绘制数条正弦光带与径向光斑（加法混合，DPR 上限 1.75，开销很低）；歌词 = DOM 文本，走主题字体。
- 主色提取与「黑胶唱片」模组同源：24×24 降采样、按饱和度 × 中间调加权，跨域污染时静默回退，按封面 URL 缓存。
- 不声明任何权限；不碰宿主 DOM、不注入全局样式、不联网。

## 权限

无。该模组只用动画模式注册表与上下文读取，不需要 `playback.read` 等任何权限。

## 隐私

不联网、不上传任何数据；主色提取在本机完成，设置由宿主保存在本机。
